# Physical layer 

> [!abstract] One-line summary
> raw bits of the network signals is transmiited in this layer.
> It ensures devices can transmit and receive raw data over physical mediums.
> It provides universal standards for cables, connectors, and signaling, ensuring compatibility
> Support for Various Media:**** Works with wired (e.g., Ethernet) and wireless (e.g., Wi-Fi) technologies.

## What is it?

layer in the OSI model where the physical data bits are transmitted.
## functions 
1. transmitts the physical data over physical medium.
2. does encoding and decoding of data to signal and signal to data.
3. ensures the signal are transmitted  correctly uses techinques like modulation .

4. decides the flow of the data . (ex:- speed , time , half duplex , full duplex) end of the day ensure the data is tranmiited smoothly 

## Physical topologies
toplogies are the diagrams which shows the the arrangment of the networking devices.
- point-to-point : - one sender and one reciever 
-  multi-point :- one sender multiple recivers.
# protocols
the protocols in the physical layer controls the data transmitted in the network.
some examples are :-
1. Ethernet (IEEE 802.3): used for wired internet 
2. wifi (IEEE 802.11): used for wireless internet
3. bluetooth (IEEE 802.15.1) : used for bluetooth
4. USB: universal serial bus
